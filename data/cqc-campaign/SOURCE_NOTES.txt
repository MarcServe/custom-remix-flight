Public email crawl (websites)
-----------------------------
Script: scripts/crawl_public_emails.py

This is automated HTTP fetch + HTML parsing (not a real human in a browser).
It extracts mailto: and visible email-like strings, validates syntax, and
checks whether the email’s domain has MX/DNS (can receive mail). It does
NOT SMTP-verify that a specific mailbox exists.

Sample output: crawled_public_emails.csv (run with --limit for tests).
Full list: omit --limit and run locally (long run; uses delays between sites).

  pip install -r scripts/requirements-crawl.txt
  python scripts/crawl_public_emails.py --delay 2

IMPORTANT — What to expect (common confusion)
---------------------------------------------
- 5,654 is the number of WEBSITES (domains) to visit, NOT the number of emails.
  Most sites do not put addresses in plain HTML (many use contact forms only),
  so the total number of extracted emails is usually far below 5,654.
- crawled_public_emails.csv grows as the crawl runs; if it stops early, use:
    python scripts/crawl_public_emails.py --delay 2 --resume
- EXPORT_all_unique_emails.csv — one row per unique email (deduped) for easy copy
  into spreadsheets or your app import.
